知光 Luma｜Google Apps Script 一鍵網站化
==========================================

目標：
把已部署的 Apps Script Web App 同時用作「測驗網站」及「Google Sheet API」。
部署完成後，原有網址無需更改。

步驟
----
1. 在 Apps Script 左側「檔案」按 + > HTML，建立檔案並命名為 Index（不要命名為 Index.html，Apps Script 會自動加 .html）。
2. 將同資料夾 Index.html 的全部內容貼入 Index。
3. 將同資料夾 Code.gs 的全部內容取代原本的 Code.gs。
4. 儲存。
5. 右上角「部署」>「管理部署」> 編輯目前部署 > 版本選「新版本」> 部署。
6. 如詢問授權，按正常流程允許。

完成後
------
教師入口：
YOUR_APPS_SCRIPT_WEB_APP_URL

學生入口：
YOUR_APPS_SCRIPT_WEB_APP_URL?mode=student

API 測試：
YOUR_APPS_SCRIPT_WEB_APP_URL?action=roster（狀態頁）
JSON：YOUR_APPS_SCRIPT_WEB_APP_URL?action=roster&format=json

注意：
- 現時根網址仍回傳 JSON；只有完成上述 Index.html 及 Code.gs 更新後，根網址才會變成測驗網站。
- setup() 可再次執行，會保留 Students / Submissions 第一列以下的資料。
- 學生入口不會顯示「教師模式」按鈕。
DeepSeek AI 設定
----------------
1. Apps Script > 專案設定 > 指令碼屬性
2. 新增 DEEPSEEK_API_KEY = 你的 API Key
3. 可新增 DEEPSEEK_MODEL = deepseek-flash
4. 新增 LUMA_AI_TOKEN = 自行設定的長隨機英數字
5. 函式選 authorizeLumaServices 並執行一次授權
6. 管理部署 > 編輯目前部署 > 新版本 > 部署
7. 回到 Luma 設定頁輸入相同的 AI 存取碼
8. 在「建立考卷」按「DeepSeek 生成」
