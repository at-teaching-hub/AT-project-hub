# 知光 Luma｜網上測驗卷生成工具

## 直接開始
1. 開啟 `luma-quiz-studio.html`。
2. 以內置的示範班別（5A / 5B）測試教師工作台和學生作答。
3. 學生可輸入班別 `5A`、班號 `1`，姓名會自動顯示為「陳一心」。
4. 完成並呈交後，會即時看到分數、評級、評語和逐題回顧；同一份考卷不能再次修改。

## 教師功能
- 建立考卷，分成多個部分。
- 每個部分可選擇教學筆記、題型、題量及作答對象：
  - 全班、上半班、下半班
  - 單數班號、雙數班號
  - 指定班號（例如 `1,3,5-8`）
- 九種題型：選擇、配對、20 字內簡答、20 字以上詳答、圖片、正反、影片、填充、繪圖。
- 系統按題型估算作答時間，提示時限是否符合「90% 時間內完成」原則。
- 題目庫以學習點索引，可重用或加入新題目。生成考卷時會抽取所選筆記的句子及關鍵詞，若題庫沒有合適題目，會直接建立基於筆記內容的新題。
- 教學筆記可新增、貼上文字，或上載 `.pdf`、`.txt`、`.md`、`.csv`；文字型 PDF 會自動抽取內容，再到筆記編輯器校對。
- 成績頁顯示開始時間、呈交時間、用時、分數、評級及作答內容。

## Google Sheet CSV 範本
`google-sheet-csv` 內有 5 個可直接匯入或複製第一列的 CSV：

| 分頁名稱 | 第一列欄位 |
|---|---|
| Students | `Class,Number,Name` |
| Submissions | `Submitted At,Quiz ID,Quiz Title,Class,Class Number,Student ID,Student Name,Score,Band,Started At,Time Used (sec),Auto Submitted,Answers JSON,Review JSON` |
| QuestionBank | `Question ID,Learning Point,Type,Prompt,Marks,Answer Key,Keywords` |
| Notes | `Note ID,Subject,Title,Learning Point,Content` |
| Quizzes | `Quiz ID,Title,Published At,Time Limit,Sections JSON` |

分頁名稱及欄位名稱需要完全一致（包括大小寫和空格）。最關鍵的是 `Students` 和 `Submissions`。另附 `luma-google-sheet-csv.zip` 方便一次下載全部範本。
## Google Sheet 設定
1. 建立一個新的 Google Sheet。
2. 開啟「擴充功能 › Apps Script」。
3. 貼上 `luma-google-sheet-apps-script.gs` 的全部內容。
4. 可先貼上 CSV 欄位及學生資料，再執行 `setup()` 一次並授權；`setup()` 只整理第一列欄位，不會清空下方的資料。這會建立：
   - `Submissions`：每次呈交的中英文欄位記錄
   - `Students`：班別、班號、姓名
   - `QuestionBank`
   - `Notes`
   - `Quizzes`
5. 部署為「網頁應用程式」：
   - 執行身分：我
   - 存取權：任何人
6. 複製 Web App URL，貼回 Luma 的「Google Sheet 同步」設定。
7. 上載學生名單 CSV 後，名單會同步到 `Students`；之後學生裝置會自動取回姓名。

### 由 Apps Script 直接發佈網站
如不想另找網站寄存，可使用 `luma-apps-script-hosted.zip`：
1. 在 Apps Script 新增 HTML 檔 `Index`，貼上 `Index.html`。
2. 以 `Code.gs` 取代原程式碼。
3. 管理部署 › 編輯目前部署 › 選擇新版本 › 部署。

完成後：
- 教師入口：現有 `/exec` 網址
- 學生入口：同一網址加上 `?mode=student`
- 名單接口：同一網址加上 `?action=roster`（顯示連線狀態頁）；程式讀取使用 `?action=roster&format=json`
## 學生連結
正式放到網站後，可使用以下形式把 Google Sheet 名單帶給學生：

```
https://你的網站/luma-quiz-studio.html?sheet=你的AppsScriptWebAppURL
```

此原型若以 `file://` 在本機開啟，部分瀏覽器可能限制跨網域 Google Apps Script 請求；放到 HTTP/HTTPS 網站後會較穩定。若未能即時同步，成績仍會保存在該裝置的本機瀏覽器，並可在教師成績頁匯出 CSV。

## DeepSeek AI 出題
系統已加入「DeepSeek 生成」按鈕。使用前請：
1. 在 Apps Script「專案設定 › 指令碼屬性」新增 `DEEPSEEK_API_KEY`。
2. 可選擇新增 `DEEPSEEK_MODEL`，預設為 `deepseek-flash`。
3. 執行 `authorizeLumaServices` 一次並授權外部請求。
4. 更新部署至新版本。

詳細步驟請參閱 `DeepSeek-API-設定指南.md`。AI 只會收到筆記文字、學習點、題型及題量，不會收到學生姓名或成績。生成後請先核對每題的來源句子及答案。
## 分數評級
- 90–100：優秀
- 80–89：優良
- 70–79：良好
- 60–69：尚可
- 50–59：可以做得更好
- 40–49：要再努力
- 30–39：可找老師幫忙
- 20–29：要找老師找出問題
- 19 分或以下：到 Sayo 平台先複習一次，再找老師

## 示範資料
內置「光合作用：從光能到養分」考卷，第二部分的作答對象設為單數班號，可直接用 5A 班 1 號和 2 號比較可見部分的分別。

## 產品化注意
這個版本是可操作的單檔案前端原型，示範資料、教師設定、班別名單和學生作答會保存在瀏覽器本機；Google Sheet 可用作跨裝置的呈交及名單記錄。若要在學校正式使用，建議加入：
- 學校帳戶登入與教師／學生角色權限
- 教師及學生分開的網站部署
- 在服務端加入題目生成與教材解析
- 對文字題及繪圖題的人工覆核流程
- 資料保存政策、家長同意及存取權限管理
